# UX archaeology register

This register records borrowed interaction patterns and the product judgement applied to them. It is evidence of lineage, not permission to copy branding or pixels.

| Source | Pattern studied | Refused | Landed here |
|---|---|---|---|
| [OSIRIS](https://osirisai.live/) | Map-first command surface, compact layer groups, URL-addressable intelligence context, visible entity counts | Its global scope, decorative density, and client download of very large public payloads | Two bounded regional context layers (`ORBT`, `PORT`), an explicit live/partial/unavailable state, regional counts, and server-side normalization/cache |
| [OSIRIS API docs](https://www.osirisai.live/docs) | Plain JSON contracts and source-specific endpoints | Treating an aggregator as independent corroboration or implying empty AIS is live coverage | Provenance in the Research Workbench, source timestamps, and a clear caveat separating reference ports from live vessel positions |
| [NASA Worldview / GIBS](https://nasa-gibs.github.io/gibs-api-docs/access-basics/) | Time-aware science imagery and discoverable layer metadata | Guessed layer IDs, silently broken tiles, and vector fire products requested as PNG | Capability-verified IDs, formats, time lags, and matrix levels; false-colour and thermal context in place of broken fire rasters |
| Existing dashboard | Dense operator HUD, playback, live maps, ticker, and evidence rails | Recasting the product as a marketing landing page | A modal research desk and compact map toggles that preserve the learned command-console grammar |
